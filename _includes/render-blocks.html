{% comment %} Include generico per il box system. Stampa i box attivi, in ordine, di un file _data/blocks_*.json. Uso: {% include render-blocks.html data="blocks_home" %} Box dinamici: id "features" (Servizi, se esiste almeno un file in _servizi) e id "progetti" (Lavori svolti, da _progetti) leggono le collection e NON usano il campo html. Gestione contenuti: admin > Servizi / Progetti. CRITICO 1: la lingua BASE e' scritta fissa come "it" (riga con page.lang != "it"). Se un clone ha default_lang diverso (es. en alla radice), le pagine non-it cercano i blocchi in _data/i18n// e quelli della radice non si leggono: tenere it alla radice o cambiare quella riga. CRITICO 2: se per una lingua NON esiste _data/i18n//blocks_home.json si usano i blocchi italiani (la home EN mostra testo IT finche' non la traduci).
